# Task 3 — Handwritten Character Recognition

**Objective:** Recognize handwritten digits (0–9).

**Dataset:** MNIST, as suggested by the CodeAlpha task sheet. The first run downloads MNIST through
TensorFlow/Keras if it is not already cached.

**Model:** Convolutional Neural Network (CNN) with convolution, max-pooling, dense and dropout layers.

**Evaluation/output:** Test accuracy and loss, classification report, confusion matrix, sample predictions,
training/validation accuracy graph, and saved Keras model.

Run from the repository root:
`python Task3_Handwritten_Recognition/handwritten_recognition.py`

This project recognizes digits, not full handwritten words or sentences.
